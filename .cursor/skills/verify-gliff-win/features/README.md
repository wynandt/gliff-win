# Client verification map

Native journeys are draft/unexecuted; host tests and cross-builds are not native
UI evidence. Start with the parent skill's isolated launch and doctor. Preserve
proof after cleanup and record each skipped entry point separately.

- [Stats](stats.md): graph toggle, live/idle metrics, JSON sample, narrow/DPI/fullscreen.
- [Tabs](tabs.md): strip and keyboard switches, independent session readouts.
- [Input](input.md): graph press/cancel and click/scroll/hover through the readout.

A configured authorized server, SSH trust and an unlocked disposable Windows
session are preconditions, not things these recipes may silently create.
